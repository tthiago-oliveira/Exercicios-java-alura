# 🏦 Sistema Banco Java & Simulação

Um projeto de estudos desenvolvido em Java orientado a objetos para simular um sistema bancário interativo de terminal. 
O sistema permite criar cadastro de cliente, gerenciar conta bancária com saldo dinâmico, simular jornadas de trabalho
para ganhar dinheiro e realizar transações.

> **Status do Projeto:** ⚠️ Em Desenvolvimento (WIP - Work in Progress)

---

## 📌 Funcionalidades Atuais

- **Cadastro de Usuário:** Leitura e validação de idade, status de estudante e dados pessoais.
- **Conta Bancária:** Geração de saldo inicial aleatório e métodos seguros para consulta de saldo e depósitos.
- **Simulação de Trabalho:** Mecanismo de sorteio de ganhos dinâmicos baseados na ação de trabalhar.
- **Interface de Terminal:** Componentes visuais utilitários (`MenuUI`) para formatação de telas e caixas de 
texto responsivas no console.
