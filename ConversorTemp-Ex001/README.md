# Conversor de Temperatura em Java

Exercício para praticar fundamentos de Java, focado na manipulação de entradas do usuário e controle de fluxo.

## Funcionalidades
- Converte temperaturas de Celsius para Fahrenheit e Kelvin.
- Suporta entradas abreviadas (`F`, `K`) e nomes por extenso (`Fahrenheit`, `Kelvin`).
- Tratamento de case-sensitivity com `equalsIgnoreCase`.
- Laço de repetição com `while(true)` para garantir que o programa só finalize com uma opção válida.
