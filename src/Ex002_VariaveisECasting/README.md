# Prática de Variáveis, Tipos Primitivos e Casting em Java

Exercício desenvolvido para praticar a manipulação de variáveis, operadores, estruturas de controle e casting na linguagem Java.

## 🛠️ Conceitos Aplicados
- **Leitura de Dados:** Uso da classe `Scanner` para interatividade no console.
- **Estruturas de Repetição:** Laços `while` para validação contínua de dados de entrada.
- **Tipos de Dados:** Manipulação de `String`, `char`, `double` e `int`.
- **Concatenação:** União de tipos primitivos (`char`) com objetos (`String`).
- **Controle de Fluxo:** Estruturas `if / else if / else` para tomadas de decisão.
