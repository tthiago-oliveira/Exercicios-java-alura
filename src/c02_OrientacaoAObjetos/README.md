# ☕ Curso 02: Aplicando a Orientação a Objetos

Neste curso, explorei os fundamentos essenciais da Programação Orientada a Objetos (POO) utilizando Java. 
O foco foi aprender a estruturar sistemas modernos, organizados e sustentáveis a partir do desenvolvimento da 
aplicação ScreenMatch, dominando a abstração do mundo real para o código e aplicando os pilares da POO para criar 
sistemas flexíveis, seguros e fáceis de manter.

---

## 📌 Conteúdos Praticados

- Modelagem de Classes e Objetos: Abstração de conceitos do mundo real em classes, atributos e métodos.
- Encapsulamento e Proteção de Dados: Controle de acesso com modificadores (private, public) e validação de atributos
via métodos getters e setters.
- Herança e Reaproveitamento de Código: Criação de hierarquias de classes (superclasses e subclasses) e
sobrescrita de métodos com @Override.
- Polimorfismo e Interfaces: Padronização de comportamentos em comum, garantindo flexibilidade e desacoplamento
entre módulos.
- Geração de Dados Dinâmicos: Utilização da classe Random para simulação de saldos e valores aleatórios.
- Tratamento de Exceções e Resiliência: Uso de blocos try-catch (InputMismatchException) para evitar que a aplicação
quebre ao ler entradas do usuário.
- Arquitetura e Separação de Camadas: Criação de classes utilitárias de UI (MenuUI) para isolar a formatação
visual e manter a classe Main limpa e legível.
