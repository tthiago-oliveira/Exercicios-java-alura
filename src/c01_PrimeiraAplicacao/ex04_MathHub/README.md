# Exercício 04: MathHub (Central de Utilitários Matemáticos)

Aplicação interativa desenvolvida em Java que atua como uma central de ferramentas matemáticas e de comparação. O sistema conta com um menu dinâmico no console que aceita navegação tanto por números quanto por nomes dos comandos.

## 📌 Funcionalidades em Desenvolvimento
- **Menu Dinâmico:** Apresentação de opções via *Text Block* formatado e leitura flexível de comandos com `.trim().toLowerCase()`.
- **Gerador de Tabuada:** Cálculo e exibição da tabuada de 1 a 10 para qualquer inteiro informado, utilizando laço `for` e formatação com `printf`.
- **Módulo de Comparação:** Leitura e análise relacional de inteiros (maior/menor, par/ímpar, positivo/negativo).
- **Módulo de Fatorial:** Cálculo do fatorial de um número inteiro.
- **Calculadora de Áreas:** Cálculo de área para geometrias plano-espaciais (quadrado e círculo)
