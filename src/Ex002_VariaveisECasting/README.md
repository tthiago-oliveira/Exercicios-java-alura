# Exercício 02: Manipulação de Variáveis, Tipos e Formatação de Saída

Projeto desenvolvido para praticar conceitos fundamentais de sintaxe Java, tratamento de dados de entrada via console e manipulação de tipos primitivos e de referência.

## 📌 Funcionalidades Desenvolvidas
- **Interatividade no Console:** Leitura de entradas do usuário utilizando a classe `Scanner`.
- **Validação de Dados de Entrada:** Estruturas de repetição `while(true)` com tratamento de exceção para escolhas inválidas.
- **Tipos de Dados:** Uso de `String`, `char`, além do controle de fluxo condicional com `if / else if / else`.
- **Formatadores de Texto:** Emprego de *Text Blocks* (`"""`) e o método `.formatted()` para exibição limpa e estruturada no console (tabela de produtos).
- **Tratamento de Strings:** Comparação case-insensitive com `.equalsIgnoreCase()` para flexibilidade de digitação do usuário.
